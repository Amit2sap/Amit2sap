# Marketing calendar: festivals, events and buying seasons (all agents)

Every agent reads this file at the start of each run and picks today's theme from it.

**Dates:** dates marked *(verify)* follow the lunar calendar and are approximate. On the 1st of every month, the Website & Search agent checks the next 60 days of dates with a web search ("<festival> 2027 date India"). It corrects this file and logs the change.

**Lead time:** pitch B2B buyers **6–8 weeks before** an occasion. Post consumer content **2–3 weeks before** it. A countdown post goes up 3–5 days before.

## How to use it on a posting day
1. Find the next occasion within 21 days. If there is one, today's post is built around it, linked to the matching collection (table below).
2. If none is within 21 days, use the channel's normal weekly mix, weighted to the "B2B pitch window" column.
3. Never post a festival greeting with no product. Every post links to a product or collection.
4. Do not post celebratory content on mourning or sensitive days (for example Muharram). For religious festivals, keep the tone respectful and use no deity images.

## Industry events to watch (B2B leads and timely posts)
Check the dates with a web search each quarter.
- **IHGF Delhi Fair** (EPCH handicrafts fair, spring and autumn editions).
- **India Gift Fair** and **Gift World Expo** (corporate gifting).
- **IIJS Premiere / IIJS Signature** (jewellery trade fairs, Mumbai). These give jeweller lead lists.
- **HICSA**, **Hotel Investment Forum India** and **FHRAI conventions** (hospitality buyers).
- **India Design ID** (interior designers and architects).
- **Wedding Asia** and **Vows Wedding Expo** (wedding planners).
