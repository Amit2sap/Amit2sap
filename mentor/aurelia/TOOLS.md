# Free tools for Aurelia

Check each tool's current age rules before suggesting sign-up; set up accounts together with her father. Note: Claude.ai itself requires users to be 18+, so she should not use Claude directly — the mentor agent runs under her father's account.

## AI study helpers (free)
| Tool | Use | Note |
|---|---|---|
| Google Gemini | Doubt solving, explain a concept "like I'm 14", quiz me | Google allows teen accounts; parent can supervise via Family Link. Rule: ask for hints and steps, not finished homework. |
| ChatGPT (free) | Same as above, practice questions | Age 13+ with parent permission per OpenAI terms. |

## Memory & focus
- **Anki** (free, Android) / **Quizlet** free tier — flashcards for definitions, dates, formulas, Literature quotes.
- **Forest** or a simple Pomodoro timer — phone-free focus sessions.
- **Google Family Link + Digital Wellbeing** (free, built into Android) — app timers, bedtime mode. Best set up *with* her, not secretly.

## Creative + AI skills
- **Google Teachable Machine** (free, no account) — train an AI on her own drawings or guitar sounds.
- **Elements of AI** (free online course) and **Code.org AI lessons** — understand how AI works.
- **Scratch** (free, MIT) → later Python basics.
- **Krita** (free drawing software), **Canva** free tier — digital art and portfolio.
- **JustinGuitar** (free lessons site/app) — structured guitar learning.
- **AutoDraw** (Google, free) — fun AI sketch experiment.

## For the board exam
- CISCE specimen question papers (cisce.org) and past papers — from Phase 3 onwards, one timed paper per week.
